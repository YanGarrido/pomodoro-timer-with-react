# ⏱️ Pomodoro Timer com React

Este projeto é um cronômetro Pomodoro desenvolvido com React e TypeScript, seguindo a técnica de gerenciamento de tempo que alterna períodos de foco com intervalos curtos. A aplicação permite que os usuários iniciem, pausem e reiniciem sessões de trabalho e descanso de forma simples e intuitiva.

🔗 Acesse a versão online: [pomodoro-timer-zeta-five.vercel.app](https://pomodoro-timer-zeta-five.vercel.app)

---

## 🚀 Funcionalidades

- **Iniciar/Pausar/Resetar**: Controle completo do cronômetro.
- **Temporizador Visual**: Exibição clara do tempo restante.
- **Notificações Sonoras**: Alertas ao final de cada sessão (se implementado).
- **Responsividade**: Interface adaptável a diferentes tamanhos de tela.

---

## 🛠️ Tecnologias Utilizadas

- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática.
- **HTML5 & CSS3**: Marcação e estilização da aplicação.

##📦 Como Executar o Projeto Localmente
1. Clone o repositório:
```bash
git clone https://github.com/YanGarrido/pomodoro-timer-with-react.git
```
2. Navegue até o diretório do projeto:
```bash
cd pomodoro-timer-with-react
```
3. Instale as dependências:
```bash
npm install
```
4. Inicie a aplicação:
```bash
npm start
````
A aplicação estará disponível em http://localhost:3000.
